## Art and audio
Generated by `node scripts/audit-assets.mjs [path-to-upstream-clone]`, which hashes every file in `public/assets` against the free *Legacy Fantasy – High Forest 2.3* pack that ships in the upstream repository's `extracted_assets/`.

- **matches pack**: byte-identical to a file of Anokolisa's *Legacy Fantasy – High Forest 2.3* (free). The creator's page says the packs may be used "freely" in commercial projects; the full licence is a Google Doc that has not been read, so redistribution rights are still to be confirmed.
- **PENDING**: no byte match. A file may be a spritesheet re-cut from that pack's frames (likely for the hero, boar and bee sheets), or come from another pack, or be generated. The upstream repository carries no credits, so provenance is unknown.
- All 5 music tracks, the portraits, the sword sprites and the companion have no known source.

**Release gate:** the game builds and runs locally with all of these assets. Before this repository is made public, every PENDING item must be traced to a source with a licence that allows redistribution, or replaced by a lookalike that does.
